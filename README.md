# 📈 네이버 증권 바닥권 반등 유망주 발굴기 (Mobile & Desktop App)

단순한 낙주가 아닌 **[52주 최저가/과매도 바닥 + 외인/기관 스마트머니 수급 + 거래량 급증 + 저평가 밸류]**가 결합된 **상승 반등 유력 종목**을 탐색하는 스마트 주식 분석 시스템입니다.

---

## 📱 1. 스마트폰 모바일 앱 실행 (Android / iPhone)

### 📲 로컬 Wi-Fi 스마트폰 연결
1. `run_mobile_server.bat` 파일 실행
2. 화면에 나타난 **QR 코드**를 스마트폰 카메라인식으로 스캔
3. 스마트폰 브라우저 메뉴에서 **[홈 화면에 추가]**를 눌러 바탕화면에 모바일 앱 아이콘 생성

### 🌐 24시간 온라인 무료 배포
- PC 없이 24시간 스마트폰에서 이용하시려면 [DEPLOY_GUIDE.md](file:///c:/Users/seong/OneDrive/바탕 화면/naver_stock_finder/DEPLOY_GUIDE.md)를 참고하세요.

---

## 🖥️ 2. 데스크톱 앱 실행 (Windows .exe)

- **무설치 독립 실행 파일**: `dist/StockFinder/StockFinder.exe` 더블 클릭하여 구동.
- **재빌드**: `cmd /c build_app.bat` 실행 시 `.exe` 독립 파일 생성.

## ⚡ 주요 핵심 기능
- **4대 전략 프리셋**:
  - 🔥 **외인+기관 쌍끌이 바닥주**
  - 💥 **거래량 폭증 매집주**
  - 🛡️ **초저평가 자산주 (PBR ≤ 1.0)**
  - ⚡ **RSI 과매도 탈출주**
- **모바일 터치 뷰 & Plotly 캔들스틱/이평선/볼린저/거래량/RSI 차트**
- **네이버 증권 모바일 간편 이동** (`m.stock.naver.com`)
- **CSV 엑셀 결과 내보내기**
